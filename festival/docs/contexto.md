# App festival
Este é um site de festival de musicas. Crie todo o projeto dessa pasta `Festival`

## Tecnologias
Use estritamente as tecnologias citadas abaixo:
- Html
- Css

Nao use nem instale nada neste projeto

Este projeto **Nao Usa** Javascript

## Referencias
- Explore a minha pasta `referencias`
- Entenda como eu programo
- Entenda as tags que eu conheço
- Voce deve fazer parecido para que eu possa compreender o seu codigo
- Voce pode usar tags e estilos novos **Se Necessario** , mas faça isso de forma contida

## Paginas
- index.html - Pagina inicial
- Turismo.html - Pagina que exibe as opçoes de lazer e turimos na cidade do festival

### Regras
- Crie um arquivos css geral compartilhado entre as paginas
- Crie um arquivo individual css para cada pagina que contem sua estilizaçao especifico
    - Os arquivos individuais devem ter o mesmo da pagina html que ele esta atrelado
